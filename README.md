# Описание проекта и инструкция по запуску

# ToDo лист API
### Описание
Благодаря этому проекту можно управлять задачами с использованием матрицы Эйзенхауэра.

Версия 2.1: добавлен плановый дедлайн `deadline_at`. Срочность теперь рассчитывается автоматически: задача считается срочной, если до дедлайна осталось 3 дня или меньше.
### Технологии
Python 3.12
fastapi 0.119
### Запуск проекта в dev-режиме
- Установите и активируйте виртуальное окружение
- Установите зависимости из файла requirements.txt
```
pip install -r requirements.txt
```
- В папке с файлом main.py выполните команду:
```
uvicorn main:app --reload
```

### Модель задачи
- Поля: `title`, `description`, `is_important`, `deadline_at`, `quadrant`, `completed`, `created_at`, `completed_at`.
- `is_urgent` не хранится, вычисляется по `deadline_at`.
- `quadrant` определяется по `is_important` и вычисленной срочности.

### API изменения
- POST `/api/v2/tasks/`: вместо параметра срочности передаётся `deadline_at` (ISO datetime). Квадрант и срочность рассчитываются автоматически.
- PUT `/api/v2/tasks/{id}`: поддерживает обновление `deadline_at`, при изменении пересчитываются срочность и квадрант.
- GET ответы по задачам дополнены полем `days_left` — количество дней до дедлайна.
- Статистика по дедлайнам: GET `/api/v2/stats/deadlines` — список задач со статусом pending в формате: название, описание, дата начала, оставшийся срок (в днях).
